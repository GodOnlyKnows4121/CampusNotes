# 校园记录与 AI 助手

Android 0.6.2，包名 `cn.campus.notes`，最低 Android 8.0（API 26）。沿用深色五页、采集与内容核对、独立会话和多语言模型，提供识别协议预检、配置示例及独立 OCR 等待策略。完整目标见 [PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md)，实际交付与待办见 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)，识别接入与三模型联动状态见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

首次启动为空库。在“更多”可主动载入示例课表与资料结构，示例带标记，不产生虚构文件。编辑示例条目后保存为个人条目。只有数据库或文件操作成功才提示已保存。

在日程设置真实学期开始日（第一周周一）、总周数及每节课时间，可按日期推算教学周。旧课程留在未设置学期的范围，保留原来 08:00/10:00/14:00/16:00/19:00 的时段含义；不以原型中的示例日期替用户设置学期。课程编辑支持跨节和 all/odd/even/custom 周次规则。

## 数据与文件边界

- Room 保存文字记录、课程、资料层级、学期/安排/待办/关联/回收站、识别任务与核对文字，以及独立会话。schema 5 经 4→5 非破坏迁移把旧对话归入“历史会话”，并增加请求配置快照；旧消息未记录的模型显示为未知，不用当前设置倒填。完整保留 1→2→3→4→5 迁移链。
- DataStore 保存地址、模型名、沙箱偏好、当前会话及密钥密文。密钥使用 Android Keystore 的 AES-256-GCM 加密，旧服务继续绑定原服务类型，新语言模型密钥独立绑定配置 ID；不回显，不进入日志或 Activity 保存状态。输入中的新密钥旋转后清空，已保存密钥保留。
- 文件通过系统 `OpenDocument` 选择，仅复制用户授权的内容到 App 私有 `files/documents`。单文件上限 100 MB；失败会回滚未完成副本。导入后不依赖外部 URI 的长期授权。

## 采集、识别与文档提取

- 首页录音申请麦克风权限后，使用 microphone 类型前台服务与常驻通知，提供暂停、继续、结束并保存。单次上限 6 小时或 512 MB；停止失败或进程中断留下的文件在“更多 → 本地存储 → 采集恢复”中主动保存或确认丢弃。真实麦克风与锁屏持续录音尚未真机验收。
- 拍照调用系统相机，原件直接写入本应用私有临时目录，确认后归入收件箱；取消不上传，也不伪造拍照成功。没有请求广泛存储或本应用相机权限。本轮按用户选择未执行真实拍照验收。
- 原件详情提供本机文字提取：UTF-8/带 BOM 的 UTF-16 文本、DOCX、PPTX、可读 PDF。上限 20 MB、60000 字；PDF 上限 200 页。旧版 DOC/PPT、加密或损坏文档、扫描 PDF、表格/公式的精确版式保真不在当前解析能力内；可保存和外部打开，扫描页需另存图片后 OCR。不会以空文字表示解析成功。
- ASR 与 OCR 分别使用已保存的服务地址、模型和密钥。兼容 Chat Completions 的 `input_audio` / `image_url` 请求适配已实现；仅在原件详情预览上传内容并确认后发送，可能计费。模型别名和代理平台能力必须以实际服务为准；ASR 与 OCR 目前各有真实合成短样本通过证据。
- 0.6.1 在设置、上传预览及请求入口检查识别协议。Anthropic Messages、Responses 等路径不能直接用于现有识别适配；官方示例只填入编辑草稿，不自动保存或联网。实际 POST 地址可预览，本地检查通过不等于账号或模型在线可用。
- OCR 的非流式请求单次最多等待约 5.5 分钟，可取消，不自动重试；对话与 ASR 时限不变。服务标记未完成时不会把结果当作完整文字确认。
- AAC/M4A（含本应用录音）在本机无损封装为每段最多 3 分钟、约 5 MB，按顺序转写；其他音频本轮限 3 分钟、7 MB。图片限 7 MB。长录音可能触发多次请求，支持取消；失败、中断的部分文字保留但不能当作完整结果确认，也不会自动重发。
- 完整处理结果先进入“待核对”，用户可修改并确认。有效版本可用于首页搜索、有限文本整理及另存文字记录；另存记录可查看来源。重新确认后使旧整理计划失效。原件不覆盖，回收站保留识别结果，永久删除原件时同时移除其识别文本，迟到任务不能重新写回。
- 重命名改变本地显示名称；删除大组/学科/主题会在确认后将其下级树移入回收站并保留副本。恢复先校验父级与冲突，永久删除才移除不再引用的本地副本。外部源文件不变。
- 打开文件时使用范围限定的 FileProvider，仅向用户选定的查看应用临时授予读取权限。没有对应查看应用时显示错误。
- 本地清理保留资料库和回收站全部引用，只移除未关联残留。备份恢复与云同步尚未实现；卸载应用会丢失本地内容，系统自动备份已关闭。
- 代理仅在所选主题的 AI 成果区新建一个 Markdown 文件，路径由应用生成 UUID。模型只能返回标题与正文；不提供删除、覆盖、移动、外部修改或任意代码执行能力。未授权沙箱自动整理时须先预览并确认；已授权时有效计划自动执行。原件和外部源文件均保留。
- 对话与任务日志新增 Room 表，提供数据库 1→2 非破坏迁移。中断、取消、断流或错误的回答保留并标注；只有完整问答进入后续上下文（最近最多 20 轮，合计 50000 字预算）。清空对话需确认，不删除另存的记录，也不代替服务商端的数据删除。

页面选项、资料层级、编辑草稿使用 Compose 保存状态，支持切页和 Activity 重建；对话/代理切换保留草稿。各会话的文字草稿、模型与强度异步保存到 Room；会话切换和新建不发送请求。生成中的任务在应用退出后标注中断，不自动重新发起付费请求。

## 使用 DeepSeek 与整理代理

1. 在“更多 → 模型配置”保存 DeepSeek API 地址、模型名与密钥。地址接受 HTTPS 基址（如 `https://api.deepseek.com`）或完整 `/chat/completions` 地址；预填模型为 `deepseek-flash`，以服务商实际可用名称为准。保存设置不调用网络。
2. 在“AI → 对话”输入并主动发送。请求发送问题和最近完整对话到配置的服务；不会自动读取资料库。支持停止，取消不保证服务商退回已产生的用量。
3. 在资料库导入 UTF-8 文本原件（TXT / Markdown / CSV / JSON），或先对音频、照片、文档主动处理并核对确认文字。在“AI → 代理”选择主题并查看所属大组规则与原件列表。点击生成会上传该主题的可用文本和规则；最多 10 份，每份 64 KB，合计 48000 字。二进制原件不会被当作文字发送，缺少确认结果时拒绝整理。
4. 未开启沙箱自动整理时，查看操作预览并确认写入；开启时自动执行有效计划。成果与原件分开存放，执行前再次校验原件和规则。来源改变、非法计划或重复执行均被拒绝；任务日志显示真实状态。

“会话”支持新建、命名、切换与确认删除；清空只影响当前消息，保留草稿及其他会话。删除会话不会删除已另存的文字记录，生成期间先停止再删除。模型下拉框中的“管理语言模型”可新增独立配置；保存不联网，移除配置保留历史消息，相关会话需重新选择模型。已有默认 DeepSeek 与 ASR/OCR 的地址、名称和密钥不会自动改写。

底部同一行提供强度与模型选择。官方 `api.deepseek.com` 的 `deepseek-flash` / `deepseek-v4-pro` 按当前官方协议支持轻量 `low`、标准 `high`、深入 `max`，发送 `thinking.type=enabled` 与 `reasoning_effort`；“模型默认”不覆盖供应商参数。未知模型/代理地址只开放默认档位，不能把温度或回复长度当作思考强度。已核验协议不代表用户账号在线可用；深入思考可能增加耗时和费用。请求开始后固定本次配置，之后修改只影响下一次请求；助手消息与整理日志记录本次模型和强度。

HTTPS 请求保留证书验证，不跟随跳转，不自动重试；401/403、余额不足、限流、服务器错误、超时和不完整流均给出提示。服务端原始错误正文不回显，以免泄露密钥或敏感内容。只有正常结束的文字回复标记成功。

0.6.0 完成 79 项本机与 12 项真机测试，并保留数据升级；当时仅核对配置、没有在线调用。0.6.1 完成 84 项本机与 12 项不联网真机测试，并按明确授权修正识别配置及各验连一次，结果见下文。自动调度 ASR/OCR、附件对话、引用检索及复习仍待后续实现。

原对话助手内容只能取得引用标记，因此页面版本表示本次需求约束，不声称精确复刻旧原型。

## 构建与运行

固定版本：Gradle 8.14.3、AGP 8.13.0、Kotlin/Compose compiler/kapt 2.2.20、Compose BOM 2025.09.01、Room 2.8.4、DataStore 1.2.1、OkHttp 4.12.0、PdfBox-Android 2.0.27.0。compile/target SDK 36，Java 编译目标 17，本机 JDK 21。

1. 使用 Android Studio 打开此目录，安装 SDK Platform 36、Build Tools 35.0.0。
2. 生成本机 `local.properties`；不要提交此文件。本机 SDK 在 `work/android-sdk`。
3. 在项目目录运行：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest
```

APK 默认在 `app/build/outputs/apk/debug/app-debug.apk`，本机交付副本在 `artifacts`。安装包、手机截图、验证日志、本机 SDK 和配置均不提交到公开源码仓库。

连接设备后用 Android Studio Run，或在干净测试设备上运行：

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

设备冒烟测试浏览现有资料，草稿使用临时独立会话并在结束后清理，不向空库自动插入示例。当前学期没有课程或资料库没有主题时，对应用例显式跳过。Keystore 测试验证测试字符串和已配置密钥可解密，不回显密钥或修改服务配置；AI 本地设备测试使用独立数据库、合成回复与单独清理的 UUID 文件，不调用模型。在线识别测试默认跳过，只有显式授权参数才执行；普通回归选择离线测试类，防止误发付费请求。当前验证见 `VALIDATION_RECOGNITION.md`，历史升级记录保留在各版本验证文档中。
